Host AEAD rejection harness
---------------------------
The host rejection harness records the actual decrypt return code for each invalid-input case.

Example rebuild command for Ascon-AEAD128 opt64:
  clang -O3 \
    -Iascon-c/crypto_aead/asconaead128/opt64 \
    -Iascon-c/tests \
    ascon-c/crypto_aead/asconaead128/opt64/*.c \
    aead_negative_tests.c \
    -o aead_negative_tests

  ./aead_negative_tests > aead_negative_tests.csv
